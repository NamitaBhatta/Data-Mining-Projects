# Data Mining Projects

A collection of data mining and machine learning projects.

## Projects

| Project | Description |
|---|---|
| [Apriori](./Apriori) | Association rule mining using the Apriori algorithm and related frequent-itemset mining techniques. |
| [Naïve Bayes](./Naive-Bayes) | Classification using Gaussian, categorical, and hybrid Naïve Bayes approaches. |
| [Decision Tree](./Decision-Tree) | Classification using decision tree algorithms with performance analysis. |
| [Artificial Neural Network](./ANN) | ANN implementation and experiments with different initialization methods, activation functions, dropout, and network architectures. |
| [K-Means](./K-Means) | Image segmentation using K-Means clustering. |
| [K-Nearest Neighbors](./KNN) | Handwritten digit classification using KNN with different distance metrics and feature-selection techniques. |
| [Principal Component Analysis](./PCA) | Dimensionality reduction and data analysis using PCA. |
