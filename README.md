# Data Mining Projects

A collection of data mining and machine learning projects exploring classification, clustering, association rule mining, dimensionality reduction, and neural networks using publicly available datasets. The projects include K-Nearest Neighbors, Naïve Bayes, Decision Trees, Artificial Neural Networks, K-Means, Apriori, and Principal Component Analysis.

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook
